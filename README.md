# lanespeak

A lean TeamSpeak 3 client for Windows: AI voice cleanup, per-person volume levelling,
whisper, soundboard, in-game overlay and channel recording.

## Download

Get the latest installer from **[Releases](../../releases/latest)** (`lanespeak-setup-x.y.z.exe`).

## Installing

The installer isn't code-signed yet, so Windows SmartScreen may say
"Windows protected your PC". Click **More info → Run anyway**.

This repository only hosts installers; the source code is private.
